# Get started with Dark

## 1. Invite the official bot

[Add Dark to Discord](https://discord.com/api/oauth2/authorize?client_id=1012459997042593802&permissions=8&scope=bot+applications.commands&redirect_uri=https%3A%2F%2Fdarks.app%2Fdashboard2&response_type=code) and choose a server you can manage. Review the permissions Discord displays before authorizing the bot.

The official application ID is `1012459997042593802`.

## 2. Open your dashboard

Visit [darks.app](https://darks.app/en/dashboard2), sign in with Discord, and select your server. You can also use `/panel` in Discord to reach the dashboard.

If the server does not appear, confirm that Dark is a member and your account has permission to manage that server. Then sign in again.

## 3. Start with one module

- **Giveaways:** choose the prize, duration, winner count, and entry conditions. Make sure Dark can post in the selected channel.
- **Moderation:** review the rules and exemptions before enabling AutoMod or guard features. Choose a log channel your team can read.
- **Welcome and roles:** select your welcome channel and roles. Discord's role hierarchy must allow Dark to manage the roles you select.
- **Tickets:** configure the support category and staff roles, then test the member flow with your team.

## 4. Check the member experience

Run a small event or test the configured module before announcing it to the whole server. Review its result in your dashboard and Discord channels.

## 5. Get help when you need it

[Join support](https://discord.gg/sQH6t2Ct9f) for setup assistance. Include the module, what you expected, and what happened. If Dark displays an error code, include that code.

See the [official documentation](https://darks.app/en/docs) for more details and the [feature guide](features.md) for a tour of the bot.
