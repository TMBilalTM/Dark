# What you can do with Dark

| Module | For your community |
| --- | --- |
| Giveaways | Set entry requirements, select winners, and manage supported reward delivery. |
| Moderation and guard | Configure AutoMod and server protection, and review moderation logs. |
| Tickets | Give members a clear place to ask for help and staff a way to organize requests. |
| Levels and economy | Give members progression, profiles, and leaderboards to return to. |
| Music | Manage voice sessions and queues, including controls from the dashboard. |
| Welcome and roles | Configure welcome messages, automatic roles, and reaction roles. |
| Automations and notifications | Set up recurring server routines and event notifications. |
| Community tools | Manage polls, reminders, invite tracking, birthdays, and private rooms. |

## Giveaways with conditions

Choose the entry conditions that fit your event: roles, server membership, account or member age, activity, voice presence, or supported connected-platform checks. Dark can re-check eligibility and manage the winner flow.

## One dashboard for your team

Select your server on the [dashboard](https://darks.app/en/dashboard2) to configure modules and view available activity information. Access depends on your Discord permissions.

## Before you configure

Feature availability, limits, and supported integrations can change. Refer to the [official documentation](https://darks.app/en/docs) and [current plans](https://darks.app/en/pricing) for details, or ask in the [support server](https://discord.gg/sQH6t2Ct9f).
